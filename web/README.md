# web/ · Vue3 + ECharts 数据大屏

**当前状态：代码结构完整、测试通过、构建可离线运行；缺的是数据。**

页面现在打开会显示「数据未接入」。这是刻意的 —— 见下方「数据为什么还不接」。

## 定位

大屏与手机 App 是**两个不同粒度**的产品，刻意分开：

| | 手机 App | Web 大屏 |
|---|---|---|
| 受众 | 学生本人、体育老师 | 教育管理者、评委 |
| 粒度 | 个人的一组动作 | 区域、年级、年份的宏观分布 |
| 数据 | 实时采集的姿态判定 | 历年全国学生体质健康统计 |
| 设备 | 手机 | 答辩现场的笔记本 |

答辩时双设备演示：手机拍动作 → 笔记本上的决策服务出结果 → 大屏呈现区域体质图景。

**五个视图**：学段对比、年度趋势、**地图热力**、分省对比、指标分布。

地图热力与分省对比看的是同一份数据，但回答的问题不同：**排名看「谁高谁低」，
地图看「高低在地理上怎么连片」** —— 沿海与内陆有没有分界、是连片还是零散，
柱状图里看不出来。

**点击下钻**：在学段对比点某个学段、或在分省对比点某个省份，会跳到它的历年趋势，
并在顶部出现一个可清除的筛选标签。趋势图与分布图上的点击**不做**下钻 ——
点一条折线的某个点要看的是「那一年的详情」，那是另一个功能，顺手接上会让人
以为点出了新数据。

**三种数据状态**：加载中 / 未接入 / 校验失败，各自有明确的呈现，
**没有一种会画空图充数**。

## 数据为什么还不接

本页面展示的是**外部公开统计数据**，不是本平台产生的结果。在确定数据来源之前
预置任何示例数字，都会在答辩现场经不起一句「这个数据哪来的」—— 而「数据合规」
本身就是评分表里技术实现与规范那一项的考量。

**所以第一件事不是写代码，是确认数据源。** 四个问题：

1. 用哪份公开数据？（教育部《全国学生体质健康调研》结果公告、
   《国家学生体质健康标准》年度实施报告、各省教育厅发布的数据？）
2. 覆盖哪些年份与地区？
3. 可视化哪几个维度？（区域分布 / 时间趋势 / 指标构成 / 与国标达标的对比）
4. 引用方式怎么写？（公开报告可直接引用，但页面上要标注来源）

数据格式与放置位置见 [public/data/README.md](public/data/README.md)。

## 两处需要留意的地方

### 地图数据：来源必须确认（重要）

ECharts **出于授权原因不再自带地图数据**，所以 `public/maps/china.geojson`
是手工放的（1.6 MB，34 个省级要素 + 8 个境界线要素）。

**坐标系已核实**（2026-10）：`crs` 声明为 `EPSG::4490`（CGCS2000，中国大地坐标系，
与 WGS84 差异在亚米级），坐标是经纬度。实测包围盒 经度 73.5–135.1、纬度 3.4–53.6，
与中国的实际范围一致 —— 纬度下探到 3.4° 说明南海诸岛在文件里。

**替换这份文件时必须保证坐标系一致。** 换成投影坐标（例如墨卡托的米制坐标，
数值在几十万量级）时 ECharts **不会报错**，只会把多边形画成一团糊在一起的东西。
核查方法：坐标应落在 经度 73–135、纬度 3–54 这个量级。

**但这份文件目前没有携带任何出处、审图号或许可信息。**

- **本地开发与界面预览**：可以用
- **进答辩材料、公开演示、任何对外场合之前：必须确认它的来源与授权**

正规来源是**自然资源部标准地图服务**，使用时有审图号要求。这不是洁癖：
地图的边界表示在竞赛材料里是会被审查的内容，而且它和数据集不一样 ——
数据集错了是数据问题，地图错了是另一类问题。

另外两点实现上的事：

**境界线要素不会被删。** 地图文件里那 8 个「境界线」是国界、省界、南海诸岛那类
要素。它们不参与数据匹配，但必须保留 —— 中国地图上南海诸岛与九段线是必须出现
的，删掉是合规问题而非视觉问题。`regions.ts` 的测试里有一条专门锁住这点。

**省名会被归一化。** 地图里是「北京市」「内蒙古自治区」，数据里常是「北京」
「内蒙古」。ECharts 按 `name` 精确匹配，对不上时地图会渲染成一片灰且**不报错** ——
所以 `regions.ts` 在注册前统一改名。五个自治区的简称不能靠去后缀得到
（会变成「广西壮族」「新疆维吾尔」），因此对照表是逐个列出的 34 条，
并有测试拿真实地图反向验证它没抄错。

### 全国值的合成规则

若数据只有分省值、没有全国汇总，系统**不会直接对各省求平均**。各省抽测样本量
差异很大，未加权的平均等于假设「北京和西藏权重相同」，得出的数字没有意义 ——
而它在图上看起来和真值一样。

因此要么提供一条全国汇总行，要么每一行都带 `sampleSize`（此时按样本量加权并
在图上注明）。两条都不满足时视图会拒绝出图并说明原因。这条规则有专门的测试
锁住（`options.spec.ts` 的 `nationalValue` 一组）。

## 与决策服务的接口

大屏展示的**个人体测自测结果**来自决策服务的 `/v1/decide` 响应；
`shared/contracts/decision_response.schema.json` 是它的结构定义。

宏观数据（区域热力图那部分）与本仓库的服务无关，是独立的数据集。
