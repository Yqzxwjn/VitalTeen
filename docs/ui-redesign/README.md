## 这一版改了什么

**一套令牌，页面里不再出现散落的数字。** 颜色、间距、圆角、字阶与动效曲线都在
`app/lib/ui/design.dart`。字号全部落在 12/14/16/18/20/24/30/36/48 这几种上，
每个文本样式都有名字（Heading / Title / Body / Button / Caption），页面里不写
`fontSize: 19` 这种值。

**背景只剩实色。** 原来首页横幅、等级徽章、成就徽章、动作图位用的是渐变；
这一版全部改成实色或同色相的浅色块。唯一的例外是练习页相机画面上面那层压暗
渐变（`squat_page.dart` 的 `_Scrim`）—— 它压的是实时视频，换成实色会把画面挡死。

**图标是应用自己画的。** `app/lib/ui/app_icons.dart` 里按 24 网格、1.6 笔画重画了
导航、卡片与操作行要用的那一套；相机 HUD 与报告页里那些功能性小图标仍然用
Material（那两屏的深色画面上，换一套只会让它们与应用其余部分脱节）。

**字体不换，靠字阶与字距建立层次。** 应用里九成文字是汉字，而 Geist、Manrope
这类西文字体没有汉字字形 —— 混排会在第一个汉字处掉回系统字体。所以这里用
系统的中文黑体，靠字重、字距与颜色分出层次。字体回退链写在 `design.dart` 的
`kCjkFallback`。

**中文字体回退要写进组件样式。** `ThemeData.fontFamilyFallback` 只作用于
`TextTheme`；AppBar 标题、按钮文字这些是整份替换的样式，不合并正文。所以
`theme.dart` 里用 `_component()` 让它们从正文字体族上长出来 —— 漏了会出现
「正文正常、按钮里的字变成方块」。

## 截图是怎么生成的

用的是 `flutter_test` 的 `matchesGoldenFile` + `--update-goldens`：把页面按真机
尺寸 pump 起来，加载系统里的中文黑体，然后写出一张 PNG。这套临时测试与生成出来
的 golden 文件没有留在仓库里 —— golden 依赖本机字体，换一台机器就会红，而它
验的是像素，不是产品规则。

要重做一遍时，按同样的做法写一个临时测试即可；产品规则那一层仍然由
`app/test/ui/` 下原有的测试守着（改版之后它们全部通过，只有几处断「图标长什么样」
的断言跟着换成了自绘图标）。
